1. O FORMATO SAI DO dominio.ts
--------------------------------------------------------------

O formato do relatório precisa estar no dominio.ts,
que é onde ficam os tipos/formatos de dados que passam entre as camadas. Assim
a gente importa o mesmo molde dos dois lados, e se um mudar,
o TypeScript avisa na hora do outro.

Então dá para apagar o type RelatorioAtendimentos do seu
arquivo e importar de lá:

Importando ficaria mais ou menos assim:   import type { DadosRelatorio } from "../dominio";

O que está no dominio.ts hoje é isto (já com a sua ideia do
porCategoria, falo dela no item 5):

   export type AtendimentoPorAgente = {
     agenteId: string;
     concluidos: number;
     tempoMedioHoras: number;
   };

   export type TotalPorCategoria = {
     categoria: string;
     total: number;
   };

   export type DadosRelatorio = {
     totalCriados: number;
     totalConcluidos: number;
     tempoMedioHoras: number;
     porAtendente: AtendimentoPorAgente[];
     porCategoria: TotalPorCategoria[];
   };

4. DUAS COISAS SOBRE OS DADOS
--------------------------------------------------------------

>>> A MÉDIA NUNCA PODE VIR VAZIA

Eu deixei o tempoMedioHoras como number, sem o null.

O detalhe é que, se o período escolhido não tiver nenhum
chamado concluído, o AVG do Postgres não devolve zero, ele
devolve vazio. Aí chegaria um vazio num campo que o molde
promete que é número.

Para resolver dentro da query:

   COALESCE(AVG(...), 0)

Assim, se a média vier vazia, o banco já devolve zero.


>>> EU JÁ SOMO UM DIA NA DATA FINAL

Isso é importante para o relatório não pegar um dia a mais.

No Service, depois de converter as datas, eu faço:

   fim.setDate(fim.getDate() + 1);

O motivo: uma data sem hora é meia-noite. Se a pessoa pede
"até 30/09" e eu passasse 30/09 00:00, um chamado criado dia
30 às 15h ficaria de fora.

Então, na prática:

   a pessoa pede      ->  até 30/09
   o que chega no fim ->  01/10 00:00

Por isso a consulta precisa usar "menor que":

   criado_em >= inicio AND criado_em < fim

Com "menor ou igual" ou somando mais um dia aí, o relatório
acaba pegando o dia 01/10 junto.
